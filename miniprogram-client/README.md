# 药王山沁养 · 对外小程序

面向 C 端用户和 B 端伙伴的微信小程序（原生开发，不需要编译）。后端是本仓库的 FastAPI 服务，接口在 `/api/c` 下。

## 这一版有什么

| 页面 | 内容 |
| --- | --- |
| 问答（首页） | 聊天形式。常见问题分「了解 / 体验 / 体验之后」三类，可点可输入；回答下方有「有帮助 / 没帮助」和相关问题 |
| 伙伴 | B 端 8 条问答（点了会带到问答页回答）、学习 / 合作意向登记 |
| 我的 | 睡眠记录、体验前 / 体验后 / 次日回访自评、资料、隐私开关、清空对话、注销账号 |
| 注册 | 微信身份自动登录；选身份（自己 / 家人 / 从业伙伴）、昵称头像（可不填）、同意协议 |

没有做：付费、预约、课程、B 端工作台。

## 问答是怎么回答的

默认由大模型（通义千问，`.env` 里 `CHAT_MODE=llm`）回答，但只许它用给它的资料：

1. 先找资料：和问题相近的审核过的问答（最多 3 条）+ 知识库里相关的卡片（书和公开资料灌进去后在这里）
2. 大模型根据这些资料组织回答，资料里没有就让它明说答不了；页面上标「AI 生成」
3. 回答要过一遍 `products/sleep/qa/chat_rules.yaml` 的检查（功效承诺、百分比数字、大段照搬原文等），不过关就作废

以下情况不经过大模型：

- 出现自伤、极端情绪等字眼：只给固定的求助引导（售后-03 的口径），不显示推荐问题，并记入后台待跟进
- 对上了中、高风险的问答（禁忌、孕期、慢性病、不适反应等）：原样给审核过的回答
- 用户点的是预设问题：原样给那一条
- 大模型出错、答不了或没过检查：退回问答匹配——对得上给原文，拿不准列出相近的几条，都没有就如实说没有并记到后台

大模型每次回答都要遵守的通用规则写在 `products/sleep/qa/assistant_rules.md`（身份、能答什么、医疗边界、说法、情绪与安全、隐私、不能做的、语气），老师和运营可以直接改，改完重启服务生效。

`CHAT_MODE=retrieval` 可以整个关掉大模型，只做问答匹配。目前每次提问是独立的，大模型不记得上一句。

每条问答的「其他问法」（`keywords`）决定了口语化的问题能不能对上，在 `products/sleep/qa/qa_v1.json` 里维护，也可以通过后台接口改。

## 在自己电脑上跑起来

1. 启动后端（仓库根目录）。本地联调时在 `.env` 里加 `WX_DEV_LOGIN=true`，然后 `docker compose up -d --build`
2. 打开微信开发者工具 → 导入项目 → 选 `miniprogram-client` 这个文件夹；AppID 先用测试号
3. 开发者工具右上角「详情 → 本地设置」勾选「不校验合法域名」
4. `src/config.js` 里的 `API_BASE` 默认是 `http://127.0.0.1:8100`，和后端端口对上即可

## 上线前要做的事

1. 注册小程序并完成主体认证、备案；在 `project.config.json` 填 AppID
2. 服务器 `.env` 填 `WX_APPID`、`WX_SECRET`，`WX_DEV_LOGIN` 保持 `false`
3. 给后端配一个已备案的 HTTPS 域名，填进 `src/config.js`，并在微信公众平台「开发设置」里加入 request 合法域名和 uploadFile 合法域名
4. 微信公众平台「设置 → 服务内容声明 → 用户隐私保护指引」里声明：昵称、头像（选中的照片）
5. `src/pages/legal/legal.js` 里的用户协议和隐私政策是草稿，补上运营主体和联系方式，交法务确认
6. 问答清单里 23 条带「待确认」的内容，逐条和沁自然、雪萍老师确认
7. 定好风险信号由谁值守、多久看一次后台（`/api/client-admin/overview` 的 `risk_pending`）

## 后台接口（用内部账号的令牌）

| 接口 | 说明 |
| --- | --- |
| `GET /api/client-admin/qa` | 全部问答，含待确认事项 |
| `PATCH /api/client-admin/qa/{id}` | 改问题、回答、其他问法、权重；`status` 改成 `draft` 即下线 |
| `GET /api/client-admin/overview` | 用户数、评价统计、没答上的问题、待跟进的风险信号、伙伴意向 |
| `POST /api/client-admin/risk/{id}/handled` | 把一条风险信号标成已跟进 |

内部小程序里还没有对应的页面，目前要在 `/docs` 页面或用工具调用。

## 检查与上传

- `npm run check`：检查页面文件是否齐全、JSON 和 JS 是否有语法错误、页面绑定的方法是否存在
- `npm run upload -- 0.1.0 "说明"`：用 miniprogram-ci 上传体验版，用法见 `ci/upload.js` 开头的说明
