# 内部小程序

## 页面

| 页面 | 说明 |
| --- | --- |
| 登录 | 填服务器地址和令牌（令牌由管理员创建） |
| 生成 | 选渠道、受众、内容类型，写补充要点，一键生成 |
| 稿件 | 按待审核 / 已通过 / 已打回筛选；运营只能看到自己的稿件 |
| 稿件详情 | 查看合规检测结果、修改（自动重新检测）、审核通过或打回、复制导出、按同样条件重新生成 |
| 知识库 | 按意思搜索知识卡片（审核人员和管理员可见） |

## 用微信开发者工具打开（不需要正式 AppID）

1. 下载并安装「微信开发者工具」，微信扫码登录
2. 选「导入项目」，目录选本仓库的 `miniprogram` 文件夹
3. AppID 处选择 **测试号**
4. 右上角「详情」→「本地设置」→ 勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
5. 在登录页填服务器地址（例如 `http://服务器IP:8100`）和令牌

左侧模拟器即可操作；工具栏的「预览」可以扫码在自己手机上打开。

## 正式上线前（需要合作方提供）

1. 正式的小程序 AppID：替换 `project.config.json` 里的 `appid`
2. HTTPS 域名：在小程序后台「开发管理 → 服务器域名」里加入 request 合法域名，并把 `config.js` 里的 `API_BASE` 改成这个域名
3. 内部使用发布为「体验版」，在后台把同事加为体验成员即可，不需要提交审核
